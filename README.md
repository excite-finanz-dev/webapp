# budgetcontrolling-forschungsverbundprojekte
---
A Single-Page-Application (SPA) designed for interactive budget controlling of research collaboration projects. The frontend is implemented with React and the backend API uses Python as well as FastAPI for data processing.

---
### 📦 Technologies
* `Cross-Platform Web`
* `React`
* `Python`
* `FastAPI`

---
### 🦄 Features
* **Interactive Spreadsheet Interface:** Single-Page-Application that presents budget data in an Excel-style table that can be viewed and edited in the browser.
* **Budget Controlling:** Supports tracking and evaluating the budgets of research collaboration projects.
* **Documentation:** Comes with documentation for usage and setup, and an interactive API documentation generated by FastAPI.
* **Open Source:** Released under the Apache License 2.0.

### 🚀 Getting Started

**1. Clone the Repository**
```bash
git clone https://github.com/excite-finanz-dev/webapp/
cd webapp
```

**2. Set Up the Backend**
From the repository root, set up and run the backend with Python 3.12 or 3.13.

Windows (PowerShell)

```powershell
python -m venv backend\.venv
.\backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\backend\.venv\Scripts\python.exe -m uvicorn project.main:app --app-dir backend/src --reload --reload-dir backend/src --port 8000
```

Linux

```bash
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.txt
backend/.venv/bin/python -m uvicorn project.main:app --app-dir backend/src --reload --reload-dir backend/src --port 8000
```

If your editor cannot resolve FastAPI or Pydantic, select the interpreter from `backend/.venv` in the editor. Use `backend/.venv/Scripts/python.exe` on Windows or `backend/.venv/bin/python` on Linux.

- [Health check](http://127.0.0.1:8000/api/health) returns `{"status":"ok"}`.
- [Interactive API documentation](http://127.0.0.1:8000/docs) shows the available endpoints.
- The local React development server can call the API from `http://localhost:5173` or `http://127.0.0.1:5173`.

**3. Set Up the Frontend**

Open a new terminal at the repository root and start the Vite development server.

```
cd frontend
npm install
npm run dev
```

### Annual cost planning demo

Open the URL printed by Vite, select a budget year and enter planned amounts in euros. Each year has one plan. The default categories are personnel, material and other. You can add or rename categories. Saved amounts refer to category IDs.

API routes are relative to `/api/projects/demo-project/budgets`. Amounts use integer cents.

| Route | Purpose |
| --- | --- |
| `GET, PUT /{year}` | Read or replace the annual plan. A PUT body maps category IDs to cents, for example `{"personnel": 250000}`. Omitted categories are set to zero. |
| `POST /categories` | Add a category using `{"name": "Travel"}`. |
| `PATCH /categories/{category_id}` | Rename a category using the same body. |

The database defaults to `backend/budgets.sqlite3`. If that file is absent and a database already exists at `backend/src/project/budgets.sqlite3`, the backend uses the existing file. Set `BUDGET_DB_PATH` to use another file. Existing standalone plans are copied on first access. Data from a previous hierarchy stays in its original tables.
