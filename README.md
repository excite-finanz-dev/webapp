# budgetcontrolling-forschungsverbundprojekte
---
A Single-Page-Application (SPA) designed for interactive budget controlling of research collaboration projects. The frontend is implemented with React and the backend API uses Python as well as FastAPI for data processing.

---
### 📦 Technologies
* `Cross-Platform Web`
* `React`
* `Python`
* `FastAPI`

---
### 🦄 Features
* **Interactive Spreadsheet Interface:** Single-Page-Application that presents budget data in an Excel-style table that can be viewed and edited in the browser.
* **Budget Controlling:** Supports tracking and evaluating the budgets of research collaboration projects.
* **Documentation:** Comes with documentation for usage and setup, and an interactive API documentation generated by FastAPI.
* **Open Source:** Released under the Apache License 2.0.

---
### 🚀 Getting Started

**1. Clone the Repository**
```bash
git clone https://github.com/excite-finanz-dev/webapp/
cd webapp
```

**2. Set Up the Backend**
From the repository root, set up and run the backend with Python 3.12.

Windows (PowerShell)

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

Linux

```bash
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn main:app --reload --port 8000
```

- [Health check](http://127.0.0.1:8000/api/health) returns `{"status":"ok"}`.
- [Interactive API documentation](http://127.0.0.1:8000/docs) shows the available endpoints.
- The local React development server can call the API from `http://localhost:5173` or `http://127.0.0.1:5173`.

**3. Set Up the Frontend**

Open a new terminal window, 
navigate to the frontend directory, 
install the dependencies, 
and start the Vite development server:

```
cd frontend
npm install
npm run dev
```
